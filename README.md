# Развлекательный бот

Игры, квизы, карта дня и ехидные комментарии.

## Игры

| Команда | Что это |
|---|---|
| `/game` | «5 букв»: бот загадывает существительное, все пишут варианты, буквы подсвечиваются 🟩🟨⬛ |
| `/квиз` | вопрос с четырьмя вариантами, очко получает первый ответивший верно |
| `/эмодзи` | угадать, что зашифровано значками — ответ пишется прямо в чат |
| `/слова` | за 3 минуты составить как можно больше слов из одного длинного |
| `/данетка` | загадка-ситуация, разгадка открывается кнопкой |

Счёт по каждой игре свой, все таблицы разом — `/топ`.

## Развлечения

- `/таро` — карта дня из колоды Тота, одна на весь чат до полуночи
- `/титул` — случайный участник получает звание дня
- `/рулетка идёт за дровами` — бот выбирает жертву
- `/morning_on` — каждое утро в 11:00 карта дня, титул дня и список игр

## Сарказм

Примерно на каждое двенадцатое сообщение (но не чаще раза в 30 минут) бот вставляет
сухой комментарий вроде «Логика безупречна. Почти как расписание электричек».
Надоест — `/сарказм выкл`.

## Содержимое

60 вопросов квиза, 25 данеток, 40 загадок-эмодзи, 40 шпилек, 25 титулов,
78 карт Таро, 656 слов для «5 букв», словарь на 41 682 существительных
и 37 длинных слов для игры в слова.

## Установка

Переменные окружения: `BOT_TOKEN`, `ALLOWED_CHATS` (id вашего чата, узнать — `/chatid`).
У @BotFather отключить Group Privacy.

Файлы: `bot.py`, `requirements.txt`, `content.json`, `tarot.json`,
`words_secret.txt`, `words_all.txt`, `words_nouns.txt`, `longwords.txt`.
